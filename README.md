# Infinite City

Браузерный 2D-симулятор строительства города с гибким редактором (TypeScript, React, Vite, PixiJS).

## Запуск
```bash
npm install
npm run dev      # разработка, адрес покажет Vite
npm run build    # production-сборка в dist/
```

## Публикация на GitHub Pages
1. Загрузите проект в репозиторий (ветка `main`).
2. GitHub → Settings → Pages → Source: **GitHub Actions**.
3. После push сборка запустится автоматически; адрес вида `https://<user>.github.io/<repo>/`.
4. Для Telegram: BotFather → `/setmenubutton` (или Web App) → этот https-адрес.

## Управление (Фаза 3)
- Колесо мыши — масштаб; камера: средняя кнопка, пробел + перетаскивание, правая кнопка, инструмент «Рука» или перетаскивание по пустому месту
- Телефон: один палец по пустому месту — камера, два пальца — масштаб
- `V` выбор/перемещение/ресайз (ручки), `B` рисование, `H` рука
- Рисование: выберите тип в списке внизу или в левой панели (жилой дом, офис, небоскрёб, склад, блок), протяните прямоугольник — ширина задаёт число модулей фасада, высота — число этажей; клик без протяжки — типовой размер
- Здание: тяните за ручки — этажи добавляются и убираются, окна и двери перестраиваются под ширину; в инспекторе — этажи, высота этажа, шаг окон, глубина, фасад, крыша, дверь, материал, балконы
- Выбранный объект: стрелки — сдвиг на шаг сетки, `Delete` — удалить, `Ctrl+D` — дубликат, `Esc` — снять выделение
- `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`) — отмена/повтор; `G` сетка, `S` привязка, `+`/`-` масштаб, `0` сброс вида, `Ctrl+S` сохранить
- Инспектор справа (на телефоне — кнопка «Свойства» внизу): имя, X, Y, ширина, высота в метрах и параметры здания

## Сохранения
Автосохранение (камера, настройки и все объекты) в IndexedDB браузера (через 0,8 с после изменений и при сворачивании страницы).
Экспорт/импорт проекта — JSON-файл. Данные хранятся отдельно для каждого адреса сайта и браузера.
